The road to 110.

Releases follow the Kriss line: 110 is 1.0, then 115 and MR3. Each release is also named after a place in Malaysia: 110 is Sungai Petani. This is where each phase stands today. Sikit-sikit, lama-lama jadi bukit.

  1. 0

    Foundations Done

    Repo, CI skeleton, signing key, and the signed [kriss] repo on GitHub Releases.

  2. 1

    Kernel Done

    linux-kriss builds in CI and boots on the dev desktop. It is in the [kriss] repo for testing.

  3. 2

    Theme, settings and a live ISO Done

    kriss-theme, kriss-settings, and a live ISO that boots to the KrissOS Shell on cosmic-comp, checked by a boot test in CI.

  4. 3

    Installer In progress

    • Calamares with the desktop picker (KrissOS Shell or Plasma), dual boot, btrfs and snapper, and Limine. Tested by an unattended install in CI.
    • Secure Boot stays on: Microsoft-signed shim, with a one-time key enrolment in MokManager. No BIOS change.
  5. 4

    Gaming Done

    kriss tune power profiles with sched_ext schedulers, and kriss-meta-gaming: Steam, GameMode, Gamescope, MangoHud and current drivers.

  6. 5

    GPU passthrough Done

    kriss-vm on desktops. Laptops with no MUX switch come next.

  7. 6

    Windows apps, local AI and moving in place Done

    WinPodX for Windows apps, set up by kriss winapps, and the AI setup in the welcome app: Ollama with GPU detection plus optional coding agents. kriss migrate turns an existing Arch or CachyOS install into KrissOS in place.

  8. 7

    Mac layout Coming

    An optional Mac layout for the shell: a top bar, a centred dock and window buttons on the left, in the same KrissOS look.

  9. 110

    Sungai Petani Goal

    KrissOS 1.0, the first tagged release.

After 110: Apple Silicon.

A separate image on Arch Linux ARM with the Asahi tooling. The shell, theme, tools and AI setup carry over; the x86 kernel, WinPodX and kriss-vm do not.
