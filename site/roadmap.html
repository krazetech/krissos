Roadmap

The road to 110.

Releases follow the Kriss line: 110 is 1.0, then 115 and MR3. This is where each phase stands today.

  1. 0

    Foundations Done

    Repo, CI skeleton, signing key, and the signed [kriss] repo on GitHub Releases.

  2. 1

    Kernel and shell test In progress

    • linux-kriss builds in CI and boots on the dev desktop. The pipeline is in review.
    • Test that cosmic-comp can host the KrissOS Shell panel, dock, launcher, notifications and lock screen. Not started.
  3. 2

    Theme, settings and a live ISO In progress

    • kriss-theme and kriss-settings are in the repo.
    • The light and dark wallpapers are in review.
    • The first live ISO boots to KDE Plasma and is being built now. The KrissOS Shell follows.
  4. 3

    Installer Planned

    Calamares with a desktop picker, btrfs and snapper with bootable snapshots, and Secure Boot through sbctl.

  5. 4

    Gaming Planned

    kriss-tune power profiles with sched_ext schedulers, and the gaming metapackage: Steam, GameMode, Gamescope, MangoHud and current drivers.

  6. 5

    GPU passthrough Planned

    kriss-vm on desktops first, then laptops without a MUX switch.

  7. 6

    Windows apps and local AI Planned

    WinBoat for Windows productivity apps, and the AI setup: Ollama with GPU detection plus optional coding agents.

  8. 110

    KrissOS 1.0 Goal

    The KrissOS Shell becomes the default desktop. KDE Plasma stays available.

After 110

Apple Silicon.

A separate image on Arch Linux ARM with the Asahi tooling. The shell, theme, tools and AI setup carry over; the x86 kernel, WinBoat and kriss-vm do not.
