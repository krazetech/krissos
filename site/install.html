Add the [kriss] repo.

Use KrissOS packages on a plain Arch install. Packages are built in CI, signed, and published to a GitHub release. KrissOS installs come with this set up already.

  1. Trust the signing key

    Import the public key, then locally sign it.

    curl -fsSL https://raw.githubusercontent.com/krazetech/krissos/main/pkgs/kriss-keyring/krissos.gpg | sudo pacman-key --add -
    sudo pacman-key --lsign-key 7C92AE8B599AF81321666CA31317AA31B21C5F87

  2. Add the repo

    Append this to /etc/pacman.conf.

    [kriss]
Server = https://github.com/krazetech/krissos/releases/download/repo-x86_64

  3. Sync and install

    Refresh the databases, then install what you want. kriss-keyring keeps the key current from now on.

    sudo pacman -Syu kriss-keyring

Check before you trust.

Packages are signed by KrissOS Packages. The private key lives only in a CI secret and an offline backup.
