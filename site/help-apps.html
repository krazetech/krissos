Apps and games.

Where your apps come from, and how to run the ones that only exist on Windows.

  • The Store
  • Games, Steam, kriss tune
  • Windows apps, Office

Install apps with the Store

Open Store from Start. Search apps and games, then Install. Each app says where it comes from: From KrissOS, or From Flathub · runs in a sandbox. Updates has Update all, and Uninstall takes a snapshot first, so you can undo it from the boot menu.

In a terminal, the same thing picks the safest place that has the app (KrissOS, Arch, Flathub, then the AUR):

kriss search WORDS
kriss install NAME
kriss remove NAME

Play games with Steam and kriss tune

  1. Check your games

    KrissOS Welcome > Game checker says whether a game's anti-cheat works on Linux, the usual reason a game won't run. Most other games run through Steam's Proton.

  2. Install the gaming pack

    In the Store, install KrissOS Gaming Pack: Steam with Proton, GameMode, Gamescope, the MangoHud overlay and the Vulkan drivers. It is also in KrissOS Welcome > Drivers and extras > Gaming pack.

  3. Pick a power profile

    kriss tune sets the power profile and the CPU scheduler together. It stays after a restart.

    kriss tune performance

    The others are balanced and powersave; kriss tune status shows what is on.

Fullscreen games open on the main display, and Alt + Tab gets you out of them. An NVIDIA card older than the GeForce 16 series uses the open nouveau driver; kriss nvidia check says whether NVIDIA's faster 580 driver fits it, and Drivers and extras installs it.

Run Windows apps and Microsoft Office

KrissOS can run the real Windows versions of your apps in WinPodX, which keeps Windows in a virtual machine and shows each app in its own window, with its own icon and Start entry. It needs about 16 GB of RAM, at least 4 CPU threads, and virtualisation (VT-x or AMD-V) on in the BIOS.

kriss winapps check
kriss winapps setup

setup fixes what is missing, then says what WinPodX changes and asks before it goes on. Read it, because it changes Windows:

  • A patch to Windows. Windows allows one remote session per user, so a second app would take over the first one's window. WinPodX patches Windows (rdprrap, based on RDP Wrapper) so each app gets its own window. Microsoft's licence terms do not allow working around Windows' limits like this, so the choice is yours. Turn it off with winpodx guest multi-session off; apps then share one window.
  • Defender exclusions. It tells Microsoft Defender not to scan C:\OEM, C:\winpodx and C:\Users\Public\winpodx.
  • Hiding the VM. It hides from Windows that it runs in a virtual machine. Turn that off with winpodx config set pod.disguise_level off.
  • The download. Windows itself, about 7.5 GB, comes from Microsoft.

Microsoft Office: in the Store, or:

kriss winapps office

It downloads Microsoft's own Office installer inside Windows and installs Word, Excel and PowerPoint (add --business for a work account). Bring your own Microsoft 365 licence: KrissOS ships no Office files and no activation tricks. Word, Excel and PowerPoint then show in Start and open their files.

This part comes with KrissOS 110 and is still being tested (#117).
