Updates and fixes.

Every update starts with a snapshot, so most mistakes take one restart to undo.

  • Update
  • Roll back a bad update
  • Reset this PC
  • Report a problem

Update KrissOS

When updates are waiting, a notification says Updates available: press Update and type your password. Or open the Store > Updates > Update all. Or, in a terminal:

sudo kriss update

It takes a snapshot first, then updates KrissOS, Arch, Flatpak apps and AUR packages together. If an update goes wrong, go back to the snapshot.

Want updates a few days early, to help catch problems? kriss channel testing. kriss channel stable goes back.

Roll back a bad update

  1. Start a snapshot

    Restart. In the boot menu, choose KrissOS > Snapshots and pick one from before the update. The 15 newest are there.

  2. Try it

    A notice says you are running a snapshot: changes are lost at the next restart, so it is safe to look around.

  3. Keep it

    If it works, open a terminal, run this, answer y and restart:

    kriss rollback

    The system you came from is kept as a backup. The command prints how to free its space once you are happy.

Reset this PC

Settings > System > Recovery > Reset this PC, as on Windows:

  • Keep my files: apps you added and your settings go. Your files in Home stay.
  • Remove everything: apps you added, your settings, every file in Home and saved Wi-Fi go.

It shows the plan, asks you to type RESET, takes a snapshot (so you can still go back from the boot menu) and finishes at the next restart. Accounts and passwords stay, and nothing is downloaded. The same in a terminal:

kriss reset --keep-files
kriss reset --everything

--dry-run only shows the plan, and kriss reset --cancel stops a reset that is waiting.

Report a problem

Settings > System > Report a problem collects the logs and a summary of this PC. Your name, Wi-Fi names and serial numbers are taken out, and you see all of it first.

  1. Say what went wrong

    Optional, but it helps.

  2. Show the report

    Read what will be sent.

  3. Send or save

    Open as a GitHub issue fills in an issue for you; nothing is sent until you press Submit on GitHub. Or Save to a file.

In a terminal: kriss report "what went wrong". When the PC is offline, it saves the report to a file in your home folder, so you can send it later.
