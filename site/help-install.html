Install KrissOS next to Windows

Windows stays. KrissOS makes room beside it, and a boot menu lets you pick one each time the PC starts. Secure Boot can stay on, and no internet is needed.

  1. Get Windows ready

    In Windows, turn off BitLocker if it is on: Settings > Privacy & security > Device encryption (or Control Panel > BitLocker Drive Encryption), and wait until decryption is finished. Keep your recovery key anyway (aka.ms/myrecoverykey). Then turn off Fast Startup: Control Panel > Power Options > Choose what the power buttons do.

  2. Make the USB stick

    Download the ISO and check it, then write it to a USB stick. A Ventoy stick works too.

  3. Start from the USB

    Restart and open the boot menu, often F12, F11, F8 or Esc while the PC starts, and pick the USB. Start it in UEFI mode, like Windows, so both share one boot menu.

  4. Trust the USB once (Secure Boot)

    With Secure Boot on, a blue screen (MokManager) appears the first time and says verification failed. Choose Enroll key from disk, pick the USB, then KRISSOS.cer, Continue, Yes and Reboot. A new ISO has a new key, so it asks again.

  5. Install

    Choose Install KrissOS. On the disk page, Install alongside is already picked: drag the divider to share the space. Encrypt system works like BitLocker and asks for a passphrase at every start. Leave it off unless you will keep the passphrase safe, as a lost passphrase means lost files.

  6. Enroll KrissOS's key (one blue screen)

    After Restart now, the blue screen shows once more. Press any key within 10 seconds, choose Enroll MOK, Continue, Yes, type the password krissos (it is not your own password) and choose Reboot. If you miss it, KrissOS asks again at the next start. Nothing in the BIOS needs changing.

If the installer says Turn off BitLocker first, or that the USB started in legacy BIOS mode, follow the steps it shows: nothing has been changed yet.

Installed with Secure Boot off? To turn it on later, run this, restart, enroll the key in MokManager as above, then turn Secure Boot on in the firmware settings:

sudo kriss-secureboot --enroll

Use KrissOS Welcome on the first start

KrissOS Welcome opens when you first sign in. It has five pages; skip any of them, and open it again any time from Start.

  • Welcome: your language, a summary of this PC, and whether it can run Windows apps.
  • Game checker: search a game to see if its anti-cheat works on Linux.
  • Bring your apps: pick the Windows apps you use, and get the KrissOS version, a Linux app that does the same job, or a web version.
  • Copy from Windows: copies Desktop, Documents, Pictures, Music, Videos and your Edge and Chrome bookmarks. Windows is opened read-only, so nothing there changes, and files you already have are never replaced. If Windows can't be opened, start Windows, hold Shift while you choose Shut down, then try again.
  • Drivers and extras: video and music codecs, printers, the gaming pack, the NVIDIA 580 driver for older cards, and local AI. These need internet.
