Tambah repo [kriss].

Nak pakej KrissOS atas Arch biasa? Semua pakej dibina dalam CI, di-sign, dan keluar di GitHub release. Kalau install KrissOS, semua ni dah siap set.

  1. Percaya kunci tandatangan

    Import kunci awam, lepas tu sign secara lokal.

    curl -fsSL https://raw.githubusercontent.com/krazetech/krissos/main/pkgs/kriss-keyring/krissos.gpg | sudo pacman-key --add -
    sudo pacman-key --lsign-key 7C92AE8B599AF81321666CA31317AA31B21C5F87

  2. Tambah repo

    Tambah ni kat hujung /etc/pacman.conf.

    [kriss]
Server = https://github.com/krazetech/krissos/releases/download/repo-x86_64

  3. Sync dan install

    Refresh database, lepas tu install apa yang anda nak. Lepas ni kriss-keyring jaga kunci supaya sentiasa terkini.

    sudo pacman -Syu kriss-keyring

Check dulu, baru percaya.

Pakej di-sign oleh KrissOS Packages. Kunci peribadi cuma ada dalam secret CI dan backup offline, tak merata.
