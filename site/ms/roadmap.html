Perjalanan ke 110.

Nama keluaran ikut barisan motor Kriss: 110 tu 1.0, lepas tu 115 dan MR3. Ni la status setiap fasa hari ni. Sikit-sikit, lama-lama jadi bukit.

  1. 0

    Asas Dah siap

    Repo, rangka CI, kunci tandatangan, dan repo [kriss] bertandatangan di GitHub Releases.

  2. 1

    Kernel Dah siap

    linux-kriss dibina dalam CI dan boot pada desktop dev. Ia ada dalam repo [kriss] untuk diuji.

  3. 2

    Tema, tetapan dan live ISO Dah siap

    kriss-theme, kriss-settings, dan live ISO yang boot ke KrissOS Shell atas cosmic-comp, disemak oleh ujian boot dalam CI.

  4. 3

    Installer Tengah buat

    • Calamares dengan pemilih desktop (KrissOS Shell atau Plasma), dual boot, btrfs dan snapper, dan Limine. Diuji dengan install automatik dalam CI.
    • Secure Boot melalui sbctl. Belum mula.
  5. 4

    Gaming Dah siap

    Profil kuasa kriss tune dengan scheduler sched_ext, dan kriss-meta-gaming: Steam, GameMode, Gamescope, MangoHud dan driver terkini.

  6. 5

    GPU passthrough Dah siap

    kriss-vm untuk desktop. Laptop tanpa suis MUX, next.

  7. 6

    App Windows dan AI lokal Dah siap

    WinBoat untuk app Windows, diset oleh kriss winapps, dan setup AI dalam app welcome: Ollama dengan pengesanan GPU berserta coding agent pilihan.

  8. 7

    Layout Mac dan pindah terus Nanti ada

    • Layout Mac pilihan untuk shell: bar atas, dock di tengah dan butang tetingkap di kiri, dalam rupa KrissOS yang sama.
    • kriss migrate: tukar install Arch atau CachyOS sedia ada jadi KrissOS terus.
  9. 110

    KrissOS 1.0 Target

    Keluaran rasmi yang pertama. Sabar sikit.

Selepas 110: Apple Silicon.

Imej lain atas Arch Linux ARM dengan tool Asahi. Shell, tema, tool dan setup AI ikut sekali; kernel x86, WinBoat dan kriss-vm tak ikut.
