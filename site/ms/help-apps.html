Pasang aplikasi dengan Kedai

Buka Kedai dari Mula. Cari aplikasi dan permainan, kemudian Pasang. Setiap aplikasi menyatakan dari mana ia datang: Daripada KrissOS, atau Daripada Flathub · berjalan dalam kotak pasir. Kemas kini mempunyai Kemas kini semua, dan Nyahpasang mengambil petikan dahulu, jadi anda boleh membatalkannya dari menu but.

Dalam terminal, arahan ini memilih tempat paling selamat yang ada aplikasi itu (KrissOS, Arch, Flathub, kemudian AUR):

kriss search PERKATAAN
kriss install NAMA
kriss remove NAMA

Main permainan dengan Steam dan kriss tune

  1. Semak permainan anda

    Selamat Datang ke KrissOS > Semak permainan menyatakan sama ada anti-tipu sesuatu permainan berfungsi di Linux, sebab biasa permainan tidak dapat dijalankan. Kebanyakan permainan lain berjalan melalui Proton dalam Steam.

  2. Pasang pek permainan

    Dalam Kedai, pasang KrissOS Gaming Pack: Steam dengan Proton, GameMode, Gamescope, lapisan MangoHud dan pemacu Vulkan. Ia juga ada dalam Selamat Datang ke KrissOS > Pemacu dan tambahan > Pek permainan.

  3. Pilih profil kuasa

    kriss tune menetapkan profil kuasa dan penjadual CPU serentak. Tetapan ini kekal selepas PC dimulakan semula.

    kriss tune performance

    Pilihan lain ialah balanced dan powersave; kriss tune status menunjukkan profil yang sedang digunakan.

Permainan skrin penuh dibuka pada paparan utama, dan Alt + Tab membawa anda keluar daripadanya. Kad NVIDIA yang lebih lama daripada GeForce siri 16 menggunakan pemacu terbuka nouveau; kriss nvidia check menyatakan sama ada pemacu NVIDIA 580 yang lebih laju sesuai untuknya, dan Pemacu dan tambahan memasangnya.

Jalankan aplikasi Windows dan Microsoft Office

KrissOS boleh menjalankan versi Windows sebenar aplikasi anda dalam WinPodX, yang menyimpan Windows dalam mesin maya dan menunjukkan setiap aplikasi dalam tetingkapnya sendiri, dengan ikon dan entri Mula sendiri. Ia memerlukan kira-kira 16 GB RAM, sekurang-kurangnya 4 bebenang CPU, dan virtualisasi (VT-x atau AMD-V) dihidupkan dalam BIOS.

kriss winapps check
kriss winapps setup

setup membetulkan apa yang kurang, kemudian menerangkan apa yang diubah oleh WinPodX dan bertanya sebelum meneruskan. Bacalah, kerana ia mengubah Windows:

  • Tampung pada Windows. Windows hanya membenarkan satu sesi jauh bagi setiap pengguna, jadi aplikasi kedua akan mengambil alih tetingkap aplikasi pertama. WinPodX menampung Windows (rdprrap, berasaskan RDP Wrapper) supaya setiap aplikasi mendapat tetingkap sendiri. Syarat lesen Microsoft tidak membenarkan had Windows dielak dengan cara ini, jadi pilihan di tangan anda. Matikannya dengan winpodx guest multi-session off; aplikasi kemudian berkongsi satu tetingkap.
  • Pengecualian Defender. Ia meminta Microsoft Defender supaya tidak mengimbas C:\OEM, C:\winpodx dan C:\Users\Public\winpodx.
  • Menyembunyikan mesin maya. Ia menyembunyikan daripada Windows bahawa Windows sedang berjalan dalam mesin maya. Matikannya dengan winpodx config set pod.disguise_level off.
  • Muat turun. Windows sendiri, kira-kira 7.5 GB, dimuat turun daripada Microsoft.

Microsoft Office: dalam Kedai, atau:

kriss winapps office

Ia memuat turun pemasang Office milik Microsoft di dalam Windows dan memasang Word, Excel dan PowerPoint (tambah --business untuk akaun kerja). Gunakan lesen Microsoft 365 anda sendiri: KrissOS tidak membekalkan sebarang fail Office atau helah pengaktifan. Word, Excel dan PowerPoint kemudian muncul dalam Mula dan membuka fail masing-masing.
