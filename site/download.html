Get KrissOS.

A preview ISO is built from main every night and published once it boots in CI. It boots straight into the KrissOS Shell.

Get the preview ISO Use the repo on Arch

What to expect.

KrissOS is still young. Try the preview in a VM or on a spare PC, not on the only computer you have. Not yet.

  • Your PC64-bit Intel and AMD PCs, with UEFI or legacy BIOS. Apple Silicon Macs come later, with their own image.
  • DesktopThe KrissOS Shell by default. The installer also offers KDE Plasma.
  • UpdatesSmall updates all the time, straight from Arch, plus our own signed packages. Each one takes a snapshot first.
  • ReleasesNightly builds go to preview. Releases are tagged by codename: 110, 115, and on.

Two settings, then boot.

  • UEFI if you have itLegacy BIOS (CSM) works too, so older PCs install fine, and CI tests both. Pick UEFI when the PC or VM offers it (OVMF in virt-manager, GNOME Boxes, VirtualBox or VMware): Windows 10 and 11 use it, so dual-boot shares one boot menu.
  • 4 GB of RAM or moreThe live session runs from memory. Two CPU cores and 3D acceleration make it smoother.
  • No login neededThe live session logs straight into the KrissOS Shell. Press the Windows key to open the launcher.

Check the image.

Download the ISO, sha256sums.txt and sha256sums.txt.sig into one folder, then check both before you write the ISO to a USB stick.

  1. Check the checksum

    It should print OK next to the ISO.

    sha256sum -c sha256sums.txt

  2. Import the signing key

    The same key signs our packages.

    curl -fsSL https://raw.githubusercontent.com/krazetech/krissos/main/pkgs/kriss-keyring/krissos.gpg | gpg --import

  3. Check the signature

    Look for Good signature from "KrissOS Packages" and this fingerprint. Each ISO also has its own .sig if you want to check it directly.

    gpg --verify sha256sums.txt.sig sha256sums.txt
    7C92 AE8B 599A F813 2166  6CA3 1317 AA31 B21C 5F87
