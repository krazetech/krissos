Choices to confirm

  1. A Windows-style Start menu. Pinned apps, Recommended recent files, then your account and power at the bottom. The Windows key opens it and typing searches straight away. Recommended reads the same recent-files list GTK apps already write.
  2. App icons on the bar. Shown as monochrome glyphs on soft tiles so cyan stays the only accent. The other option is the apps' own Papirus colours.
  3. Workspaces as dots. The active one stretches into a cyan pill. Numbers or window thumbnails are the alternatives.
  4. Notifications stack above the tray, bottom right, close to the bell. No separate notification centre in the first version.
  5. The light variant changes windows, bar, launcher and toasts. The wallpaper and lock screen stay dark.
  6. Focus ring is a 3 px cyan ring with a 14 px corner radius, set in cosmic-comp. Unfocused windows get a faint rim only.
