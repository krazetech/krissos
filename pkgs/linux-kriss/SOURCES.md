# linux-kriss sources

Generated by `tools/ci/kernel-sync.sh`; do not edit by hand.

The kernel is vanilla Linux 7.3.5 from kernel.org plus the patches below, all GPL-2.0.
They come from CachyOS's public source repositories and are built from source in our CI.
Patch contents are unmodified; each file keeps the upstream commit headers.

- Patch series: https://github.com/CachyOS/linux tag `cachyos-7.3.5-1` (f6a0828f06cb5dfee3affc3e3fba124da1e1cd4d), on top of Linux 7.3.5 (988117cc1bb17338c586a4e21ade88b5397eac33).
  One patch per step on the tag's first-parent history, which is one per topic branch.
- `config`: https://github.com/CachyOS/linux-cachyos `linux-cachyos/config` at 271d7782ac4854255aec73370aa0e142afb5d3ba.
  The PKGBUILD is derived from `linux-cachyos/PKGBUILD` in the same repository.
